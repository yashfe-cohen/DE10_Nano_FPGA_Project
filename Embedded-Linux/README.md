# 🐧 מדריך בניית Embedded Linux ל-DE10-Nano

ברוכים הבאים לחלק של מערכת ההפעלה!

כאן ריכזתי את כל השלבים לבניית מערכת **Embedded Linux** מותאמת אישית עבור לוח ה־**DE10-Nano**, החל ממנהל האתחול (U-Boot), דרך קימפול ליבת הלינוקס (Kernel) ועד לבניית מערכת הקבצים (RootFS).

במקום להשתמש באימג'ים מוכנים, נבנה כאן את כל רכיבי המערכת מאפס, במטרה להבין כיצד כל חלק במערכת עובד וכיצד כל הרכיבים מתחברים יחד.

---

## 🎥 מומלץ לעקוב גם אחרי סרטון ההדרכה

לצד המדריכים הכתובים, מומלץ מאוד לעבוד במקביל עם סרטון ההדרכה המצוין שמלווה את תהליך בניית המערכת.

המדריכים בפרויקט נכתבו בהתאם לשלבי העבודה המופיעים בסרטון, אך כוללים הסברים נוספים, הערות חשובות, פקודות מסודרות וטיפים מניסיון אישי, במטרה להפוך את תהליך העבודה לפשוט וברור יותר.

כך תוכלו גם לראות בצורה ויזואלית כיצד כל שלב מתבצע בפועל וגם להיעזר במדריכים הכתובים כמעין "דף עבודה" מסודר במהלך ההתקנה.

📺 **סרטון ההדרכה:**

## 🙏 תודות

תודה רבה ליוצר הסרטון על ההשקעה הרבה בהכנת סדרת ההדרכה המקיפה.

הסרטון היווה מקור לימוד והשראה משמעותי במהלך העבודה על הפרויקט, והמדריכים הכתובים בפרויקט זה נועדו להשלים אותו באמצעות הסברים מפורטים יותר, סדר עבודה ברור ופקודות מסודרות.
